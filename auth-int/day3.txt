Day 3 — Backend Auth Endpoints (signup + login)                                                                                                                 
                                                                                                                                                                    
  What you'll build:
                                                                                                                                                                    
  Two new endpoints:                                                                                                                                              
                                                                                                                                                                  
  POST /auth/signup — takes {email, password}, creates user, returns JWT                                                                                            
  - Validate email format
  - Check email not already taken                                                                                                                                   
  - Hash password with bcrypt                                                                                                                                     
  - Insert into users                                                                                                                                               
  - Generate JWT with {user_id, exp}                                                                                                                              
  - Return {access_token, token_type: "bearer"}                                                                                                                     
   
  POST /auth/login — takes {email, password}, verifies, returns JWT                                                                                                 
  - Look up user by email                                                                                                                                         
  - Compare password against stored hash using bcrypt.verify()                                                                                                      
  - If match: generate JWT, return it                                                                                                                             
  - If no match: return 401 (and don't say whether it was the email or password that was wrong — that leaks information)                                            
                                                                                                                                                                    
  Libraries:                                                                                                                                                        
                                                                                                                                                                    
  - passlib[bcrypt] — password hashing                                                                                                                              
  - python-jose[cryptography] or PyJWT — JWT creation/verification                                                                                                
                                                                                                                                                                    
  Key concept — the get_current_user dependency:                                                                                                                    
                                                                                                                                                                    
  Right now your verify_api_key in dependencies.py returns nothing — it's a gate with no identity. You'll replace it with:                                          
                                                                                                                                                                    
  async def get_current_user(token: str = Depends(oauth2_scheme)) -> UserModel:                                                                                     
      # decode JWT                                                                                                                                                
      # extract user_id                                                                                                                                             
      # fetch user from DB
      # return UserModel                                                                                                                                            
                                                                                                                                                                  
  This function becomes a FastAPI dependency — any route that needs to know who's calling just declares user: UserModel = Depends(get_current_user). FastAPI calls  
  it automatically before your route handler runs. If the token is invalid, it raises 401 before your code even executes.
                                                                                                                                                                    
  Task for Day 3:                                                                                                                                                 

  1. Install passlib[bcrypt] and PyJWT
  2. Create backend/src/app/services/auth.py with functions: hash_password(), verify_password(), create_access_token(), decode_access_token()
  3. Create signup and login routes                                                                                                                                 
  4. Replace verify_api_key with get_current_user                                                                                                                   
  5. Test with curl or Postman — signup, get token, call /chat with Authorization: Bearer <token>, call without token and confirm 401
