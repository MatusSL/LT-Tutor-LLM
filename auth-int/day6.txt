Day 6 — Security Hardening + Review                                                                                                                               
                                                                                                                                                                    
  Things most tutorials skip:
                                                                                                                                                                    
  1. Password requirements — enforce minimum length (8+ chars). Don't enforce ridiculous rules (must have uppercase + symbol + blood type) — they make passwords    
  worse, not better. Length is king.
  2. JWT expiry — start with 24 hours. Too short = annoying. Too long = dangerous if stolen. Production apps use refresh tokens (a separate token that can mint new 
  access tokens) — skip this for now, but know it exists.                                                                                                           
  3. Rate limiting on login — without it, an attacker can try thousands of passwords per second. Add a simple in-memory rate limiter (or use slowapi).
  4. CORS tightening — your allow_origins=["*"] in main.py:32 lets any website call your API. For now it's fine (mobile app), but know that in production you'd     
  restrict this.                                                                                                                                                    
  5. RLS final check — try to bypass it. Use Supabase's SQL editor to query as one user and try to read another user's data.
